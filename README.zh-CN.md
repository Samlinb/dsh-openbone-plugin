# OpenBone Studio：在 DSH 中制作骨骼动画

[English](README.md)

通过对话查看和调整骨骼动画，在浏览器中播放预览，再根据效果继续修改。插件已内置 Web Runtime，无需另外下载预览播放器。

## 安装插件

在 DSH 插件安装界面输入：

```text
dsh-openbone-plugin@0.2.4
```

安装完成后，重启对应的 DSH profile。也可以使用命令行安装：

```sh
dsh plugin --profile <你的profile> add dsh-openbone-plugin@0.2.4
```

请选择实际运行 DSH 网页版或桌面版的 profile。

## 连接 OpenBone

使用前需要兼容的 DSH 版本、Node.js 24.9 或更新版本，以及可用的 OpenBone 服务。请向服务管理员获取连接地址和访问密钥。

在运行 DSH 的服务器上配置以下环境变量：

| 变量 | 填写内容 |
| --- | --- |
| `OPENBONE_LIBRARY_URL` | 管理员提供的服务地址 |
| `OPENBONE_LIBRARY_TOKEN` | 管理员提供的访问密钥 |

如果使用远程 DSH 网页版，应配置服务器端环境。修改连接配置后，重启 DSH。

## 开始制作

在启用插件的聊天中，先让 DSH 连接工程：

> 列出可用的 OpenBone 工程，并把当前聊天连接到我要修改的角色。

接着查看已有动画：

> 这个工程有哪些动画？先帮我看一下行走动作。

提出具体的修改需求：

> 把行走动画的手臂摆动幅度稍微减小，然后生成预览。

也可以从动作参考开始：

> 找一个适合小短腿角色的行走参考，帮我基于它创建新工程。

如果新工程暂时无法连接，请先联系管理员将它设为可用，再继续制作。

## 查看动画预览

让 DSH 生成预览后，打开返回的链接。可以在 DSH 浏览器或自己的浏览器中观看。

播放器支持：

- 切换动画和皮肤。
- 播放、暂停、循环和调速。
- 拖动时间轴、适应画面。
- 保存 PNG 截图。
- 切换中英文界面。
- 选择 OpenBone 或 Spine WebGL 播放方式。

Spine WebGL 的使用遵循随包附带的许可说明。

再次修改动画后，请让 DSH 生成新的预览；已经打开的预览不会自动更新。链接失效时，重新生成即可。

## 反馈、撤销和保存

根据看到的效果继续反馈：

> 落地还是有点生硬，把结束前身体旋转的变化放缓，再让我看一下。

需要还原时：

> 撤销上一次修改，重新生成预览。

确认效果后：

> 保存当前 OpenBone 工程。

服务重启前请先保存工作。每个聊天可以连接一个工程；需要切换时，让 DSH 列出可用工程并更换连接。

## 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 安装后没有可用工具 | 重启安装插件时使用的同一个 DSH profile。 |
| 无法连接服务 | 请管理员检查服务地址、访问密钥和服务运行状态。 |
| 没有可用工程 | 请管理员将工程设为可用，再让 DSH 重新列出工程。 |
| 预览仍然是修改前的效果 | 在修改完成后请求生成新的预览。 |
| 预览链接失效 | 让 DSH 重新生成预览。 |
| 修改或保存提示冲突 | 让 DSH 重新读取当前工程状态，再继续操作。 |

插件内置的是预览播放器；编辑和保存工程仍需连接 OpenBone 服务。
